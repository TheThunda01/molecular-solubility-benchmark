# Assumptions and design choices

The comparison asks how specified evaluation rules behave on one historical table. It does not establish a general chemical model or a validated decision rule. A useful rationale is different from empirical evidence that a setting is best.

| Assumption or choice | Rationale and evidence | What is actually checked | Consequence if it fails or changes |
| --- | --- | --- | --- |
| The reported values can be modeled together as log10 molar solubility. | This is the source benchmark’s endpoint ([Delaney, 2004](https://doi.org/10.1021/ci034243x)); keeping it preserves the task. Measurement heterogeneity is a known limitation ([Llompart et al., 2024](https://doi.org/10.1038/s41597-024-03105-6)). | Finite values and original-source matching, not assay compatibility. | Unknown pH, temperature, solid form and measurement method can create unexplained variation; no standardized intrinsic-solubility claim follows. |
| The 1,128 processed records faithfully select original observations. | Matching structure text and targets rounded to six decimals bridges serialization differences; final target text comes from the original file. | Every selected pair matches, input hashes and rebuild output agree. | This establishes correspondence, not measurement accuracy. The reason 16 original-table rows are absent remains unknown. |
| Canonical isomeric identity is the duplicate unit. | A reproducible toolkit definition keeps repeated encoded structures together. It does not resolve every chemical equivalence. | 1,117 identities, 11 additional rows; no identity crosses either outer split or the matching inner grouping. | Salts, tautomers, protonation and unspecified stereochemistry can still complicate independence. No normalization is silently assumed. |
| Preserve repeated observations without averaging. | Retaining source records avoids inventing a measurement aggregation rule; curation can matter but is context-dependent ([Meng et al., 2022](https://doi.org/10.1038/s41597-022-01154-3)). | Duplicates remain together; metrics weight each row equally. | Identities with extra rows receive more weight. These rows are not established independent biological replicates. |
| Nine descriptors are sufficient for a useful baseline exercise. | Small, inspectable features make a manageable comparison; excluding the source ESOL prediction prevents importing that fitted model into the feature set. | RDKit definitions, feature ordering and no source prediction/label-derived features. | Missing solid-state and assay information, correlated descriptors and representational collisions can limit predictions. Sufficiency is not demonstrated. |
| A roughly 80/20 outer division is useful. | A pragmatic training/evaluation compromise, not a power calculation. Random grouping targets a fraction of groups; scaffold allocation targets rows while preserving whole groups. | Both specific partitions contain 902 training and 226 test records. | Another dataset or group size distribution can yield different proportions and scores. One seed gives no split-to-split uncertainty estimate. |
| Nonchiral Murcko scaffold is a meaningful grouping. | Ring/linker grouping has a recognized chemical rationale ([Bemis and Murcko, 1996](https://doi.org/10.1021/jm9602928)); pinned RDKit specifies the implementation. | Zero scaffold overlap in the scaffold partition; nearest fingerprint similarity also reported. | Different scaffolds can remain similar, as shown in another task by [Guo et al. (2025)](https://doi.org/10.1186/s13321-025-01039-8). This is not proof of chemical novelty. |
| Put all 317 acyclic records into one group. | They share the empty Murcko scaffold; an explicit group avoids silently dispersing them. This is conservative for that definition, not an evidence-based universal grouping. | One declared `<ACYCLIC>` group; no group crosses splits. | It can dominate a fold and changes test composition. Scores are conditional on this rule. |
| Largest-first deterministic scaffold assignment defines the challenge. | Repeatable whole-group allocation avoids outcome-based selection; the lexical tie rule removes ambiguity. | Exact membership fingerprints. | It favors large groups in training and smaller groups in testing. Comparison with the random partition does not isolate a causal effect of scaffold separation. |
| Training-only grouped CV can choose among small fixed grids. | Grouped folds and training-fitted preprocessing limit the specified forms of leakage ([scikit-learn, 1.8.0](https://scikit-learn.org/1.8/common_pitfalls.html)). | Five folds for this data, group separation, scaling inside the ridge pipeline; no test-driven search. | CV remains conditional on the groups and candidates; it does not show optimal model selection or eliminate human benchmark knowledge. |
| Mean fold RMSE is the selection objective. | This is the explicit GridSearchCV scoring rule, with equal weight per fold. | Candidate scores and chosen settings retained. | Unequal fold sizes, especially the acyclic group, differ from pooled row-weighted RMSE; the choice may affect selection. |
| Ridge alphas 0.1/1/10/100 and the 150-tree forest’s small grid are adequate baselines. | Pragmatic complexity and runtime choices fixed before this evaluation. They are not supported as optimal by the cited studies. | Recorded grids, training-only search and frozen refits. | Broader searches or alternative representations can change results; this is no ranking of all molecular prediction methods. |
| Nearest standardized-descriptor distance can describe errors. | Training-only scaling gives a defined Euclidean metric; training leave-one-out quantiles give transparent bins. | Means/scales and 50th/90th cutoffs fit only to training rows. | Correlation, duplicate zero distances and representation limitations matter. Bins are not calibrated reliability thresholds. |
| Radius-2, 2,048-bit Morgan similarity and threshold 0.8 are useful descriptive checks. | Familiar, reproducible structural summaries; settings and threshold are pragmatic reference choices. | Nonchiral fingerprints and nearest-training Tanimoto values. | Hash collisions and omitted stereochemistry prevent identity or universal novelty claims; 0.8 is not a validated acceptance boundary. |
| Held-out arithmetic can be independently reconstructed. | Exporting source-linked predictions permits checking a completed evaluation. | Exact keys/truth, source hashes, six metric rows and tolerances; no fit in verifier. | Agreement does not identify a unique generating estimator, establish authenticated provenance or validate the measurements. |
| Exposed outcomes remain an evaluation record, not a fresh blind test. | The same source row can train in one strategy and test in the other; users can see all labels. | Per-strategy membership preserved; no pooled score produced. | Further tuning after inspection requires a new evaluation design for confirmatory claims. |
| Data and software have separate reuse terms. | The live ACS Figshare record identifies CC BY-NC 4.0 for the source data; original software is MIT. | License metadata and attribution checked; no legal interpretation beyond recorded terms. | Code availability does not grant unrestricted commercial reuse of adapted measurements. |

The [glossary](glossary.md) defines terms. The [reference audit](reference-audit.json) records which sources were checked and their limits.
