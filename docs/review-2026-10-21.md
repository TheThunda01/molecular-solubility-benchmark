# Maintenance and scientific review — 21 October 2026

This follow-up covered the README, current methods and chemistry explanations, provenance, data terms, glossary, assumptions, audit/prediction guides, and saved reports. Original measurements, partitions, model choices, and reference outputs were retained.

## Findings and changes

The results remain a comparison of two different fixed test partitions, not an estimate of the causal effect of scaffold separation. Both partitions keep repeated canonical structures together. Their different composition and the large acyclic group remain material limits. Distance bins are descriptive diagnostics; the project does not provide calibrated prediction reliability.

The current ACS Figshare metadata confirms the supporting-file identity and CC BY-NC 4.0 terms. Delaney's and Llompart et al.'s PubMed abstracts were rechecked for original-model context, measurement variation and evaluation limits. Versioned GroupKFold documentation was checked against the grouping description. This follow-up did not repeat a full-paper or supplement appraisal; its specific checks are appended to the [reference audit](reference-audit.json).

The output-protection test previously attempted a directory symlink unconditionally. It now tests deterministic exports and ordinary path protection separately from the broken-symlink case. If the host cannot create a symlink, only that case is skipped. The Ubuntu CI job retains the symlink check; a Windows job now runs the same suite and reproduction command.

## Verification

On this Windows host, 50 tests ran: 49 passed and the symlink-specific test was skipped because the required privilege was unavailable. The full study reproduced all six metric rows, selected settings, and split fingerprints. The split audit checked 2,256 assignment rows. A fresh export of 1,356 held-out predictions independently reproduced six baseline metric rows. A fresh checkout with Windows CRLF conversion enabled produced the same test outcome and reproduced the full study. No new model search or data selection was introduced.
