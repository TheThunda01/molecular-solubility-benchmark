# References and what they support

- **Delaney JS (2004).** ESOL: Estimating Aqueous Solubility Directly from Molecular Structure. *Journal of Chemical Information and Computer Sciences* 44(3):1000–1005. [doi:10.1021/ci034243x](https://doi.org/10.1021/ci034243x). Original study and measured-data provenance. This project does not reproduce the published fitted equation.
- **ACS Figshare supporting data.** [doi:10.1021/ci034243x.s001](https://doi.org/10.1021/ci034243x.s001), item 7944677. Source of the matched records and CC BY-NC 4.0 data license. Metadata retrieved October 20, 2026.
- **Llompart P, Minoletti C, Baybekov S, Horvath D, Marcou G, Varnek A (2024).** Will we ever be able to accurately predict solubility? *Scientific Data* 11:303. [doi:10.1038/s41597-024-03105-6](https://doi.org/10.1038/s41597-024-03105-6). Context for measurement definitions, data overlap, and external evaluation. Its reported results are not reproduced or transferred to this benchmark.
- **Bemis GW, Murcko MA (1996).** The Properties of Known Drugs. 1. Molecular Frameworks. *Journal of Medicinal Chemistry* 39:2887–2893. [doi:10.1021/jm9602928](https://doi.org/10.1021/jm9602928). Conceptual basis for framework grouping; the executable implementation here is RDKit's nonchiral Murcko scaffold function.
- **Wu Z et al. (2018).** MoleculeNet: a benchmark for molecular machine learning. *Chemical Science* 9:513–530. [doi:10.1039/C7SC02664A](https://doi.org/10.1039/C7SC02664A). Benchmarking context and the curated Delaney task. Different features, partitions, and model grids make this project's scores non-equivalent to its benchmark table.
- **Guo Q, Hernandez-Hernandez S, Ballester PJ (2025).** UMAP-based clustering split for rigorous evaluation of AI models for virtual screening on cancer cell lines. *Journal of Cheminformatics* 17:94. [doi:10.1186/s13321-025-01039-8](https://doi.org/10.1186/s13321-025-01039-8). Recent primary evidence that scaffold distinctions can leave structural similarity across partitions. Its task is virtual screening, not ESOL solubility; no direct effect-size extrapolation is made.

## Official software references

[DeepChem's Delaney loader](https://github.com/deepchem/deepchem/blob/master/deepchem/molnet/load_function/delaney_datasets.py) identifies the same measured-solubility target and source download. Our code uses neither DeepChem's loader nor its featurizers; the 80/20 partitions and training-only CV are separately specified. A published score from another pipeline is not automatically comparable.

[RDKit's Murcko scaffold implementation](https://github.com/rdkit/rdkit/blob/master/rdkit/Chem/Scaffolds/MurckoScaffold.py) and [official API documentation](https://www.rdkit.org/docs/source/rdkit.Chem.Scaffolds.MurckoScaffold.html) define the function called here. RDKit is an explicit dependency, pinned to 2025.9.1 for this run. “Scaffold split” is therefore a concrete implementation choice, not a universal guarantee about chemical novelty. These sources were checked on October 20, 2026.
